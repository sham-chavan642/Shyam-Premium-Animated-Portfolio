# SHYAM Premium Animated Portfolio

A premium dark, animated React + Vite portfolio inspired by the structure of the supplied reference site.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Deploy on Vercel

Import this folder/repository into Vercel. Vercel will detect Vite automatically.

## Included

- Clear original profile photo with separate animation effects
- Animated rings, scan line, floating tech tags and glass panels
- HOME / SYSTEM / PROFILE / MODULES / PROJECTS / ACHIEVEMENTS / RESUME / CONTACT
- Weather Genius AI live demo:
  https://weather-genius-ai-seven.vercel.app/
- Resume PDF
- Responsive mobile layout
